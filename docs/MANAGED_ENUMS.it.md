# Enum gestiti

Gli enum sono cataloghi versionati con chiave tecnica stabile, etichetta
localizzata, descrizione e stato attivo. Le UI usano un selettore ricercabile;
la chiave resta un dettaglio avanzato e la validazione backend è autorevole.

Un valore storico disattivato resta leggibile nei dati esistenti ma non è
proponibile per nuove scritture senza una migrazione esplicita.
