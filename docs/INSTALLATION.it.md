# Installazione

Installare le dipendenze Node.js, configurare le variabili richieste e scegliere
SQLite standalone oppure PostgreSQL completo. Eseguire migrazioni e bootstrap
prima di avviare il Web; i comandi completi e i prerequisiti sono nel runbook
di installazione.

Una nuova installazione parte senza entità operative: il bootstrap prepara il
catalogo tecnico minimo. Creare dati e utenti operativi seguendo `FIRST_RUN.md`.
