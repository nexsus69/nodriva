# Interfaccia responsive

Le schermate amministrative devono funzionare su viewport stretti e larghi,
con contenuti leggibili, azioni raggiungibili da tastiera e tabelle con una
strategia esplicita per overflow o colonne secondarie.

Il layout non deve perdere bozze, lock, errori o indicatori di stato quando
cambia orientamento o si riapre la pagina.
